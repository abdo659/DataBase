# 🗄️ Database & SQL Practice

A collection of **SQL** and **Database** exercises designed to strengthen database design, querying, and data manipulation skills using relational database management systems.

This repository demonstrates practical experience with SQL through hands-on assignments, covering everything from basic queries to advanced database operations.

---

## 📖 Project Overview

The purpose of this repository is to practice relational database concepts and develop strong SQL skills by solving real-world database problems.

The exercises focus on writing efficient SQL queries, designing normalized databases, and performing data manipulation and retrieval operations.
